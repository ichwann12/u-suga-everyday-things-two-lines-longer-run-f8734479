Two lines explaining one everyday thing to a 10-year-old. Line 1 explains a
traffic jam with a school-canteen queue analogy; line 2 says why that analogy
works and what it leaves out.

Run it with Node 22:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

It reads `entry.txt` and writes it unchanged to `out/entry.txt`.
